看懂大學的極限公式

把「無限靠近」這個玄妙的想法，變成一個誰都能玩的數字遊戲。

limx→x₀ f(x) = L ⟺ ∀ ε>0, ∃ δ>0 s.t. 0 < |x − x₀| < δ ⟹ |f(x) − L| < ε

貳 認識兩位玩家：ε 與 δ

審查官出題，你來防守

極限「存在」其實是一場攻防遊戲。函數 f(x) 是一台「輸入 x、輸出答案」的機器，兩位玩家輪流出招：

🎯
審查官 ＝ ε（epsilon）
在目標 L 上下畫一條「誤差容忍帶」：結果必須落在 L ± ε 之內。ε 可以越畫越小、越來越嚴格。
🏹
你 ＝ δ（delta）
找出一個「安全靠近距離」δ：只要 x 與 x₀ 距離小於 δ，就保證命中——f(x) 一定落在帶子裡。
🏆 勝利條件：不管審查官把帶子畫得多窄（ε 任意小），你都能找到對應的 δ 守住。永遠不會輸——極限就存在。

調整看看…
直線：δ 與 ε 成簡單正比，δ = ε ÷ 2。
肆 兩種機器，兩種 δ 的算法

線性 vs 非線性：δ 不一定是 ε ÷ 2

直線　limx→2(2x+1)=5

距離：|(2x+1)−5| = 2|x−2|。要它 < ε，只需 |x−2| < ε/2。

所以 δ = ε ÷ 2。ε=0.1 → δ=0.05；ε=0.02 → δ=0.01。

δ 與 ε 成固定比例，因為直線斜率固定（=2）。

曲線　limx→1 x² = 1

距離：|x²−1| = |x−1|·|x+1|。x 越大時 |x+1| 越大，曲線越「陡」。

解 (1+δ)² ≤ 1+ε 得 δ = √(1+ε) − 1。ε=0.1 → δ≈0.0488；ε=0.02 → δ≈0.00995。

δ 與 ε 不再成正比！這就是非線性函數的關鍵差異。

🔑 不論線性或非線性，重點都一樣：給我任意 ε，我永遠交得出對應的 δ。算法不同，但「找得到」這件事不變——所以兩個極限都存在。

這是正常的 f(x)=2x+1，在 x=2 時輸出 5。

點上方兩顆按鈕，把機器切到「壞掉」狀態看看——在 x=2 挖一個洞，當 x 從兩側靠近 2，f(x) 仍然 → 5。

🔒 看完「正常機器」與「壞掉的機器」兩種狀態後，下方的關鍵結論就會出現。
🧠 這正是 0 < |x−x₀| 的用意：我們從不問 x=x₀ 那一點。牛頓時代「那個無限小量是不是零」的爭論，在這個定義下根本不會發生。
柒 三句話總結

把整個故事收進三句話

一

極限是「趨向」

越來越靠近、卻永遠不到達的目標。我們看過程，不看終點。

二

ε 是對方的刁難

「能容忍多大誤差」由審查官任意指定，且可無限縮小。

三

δ 是你的回應

為了滿足誤差，你必須靠多近。永遠找得到 δ，極限就存在。

✨ 這個定義最偉大之處，是把「無限靠近」這個動態又哲學的概念，變成純粹的數字遊戲：給我任意 ε，我交出對應的 δ。沒有幽靈、沒有神祕的消逝量，只有可以計算的不等式。
